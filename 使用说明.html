TrainLog 使用说明

正式使用方式

想让手机像独立 App 一样使用，不需要电脑一直开着，请把整个 trainlog 文件夹或 TrainLog-PWA.zip 部署到 HTTPS 网站，例如 Cloudflare Pages、Vercel、Netlify 或 GitHub Pages。

部署后，用手机打开 HTTPS 链接，在浏览器菜单里选择“添加到主屏幕”。之后 TrainLog 会像 App 一样从桌面打开。

数据同步

手机和电脑要共享数据，必须有一个云端同步端点。TrainLog 现在已经内置同步面板：

  1. 打开 TrainLog 的“复盘”页面。
  2. 找到“独立 App 与同步”。
  3. 填入同步端点和同步密钥。
  4. 手机点“上传到云端”，电脑点“从云端恢复”，或反过来使用。

没有同步端点时，TrainLog 会本地优先运行，数据只保存在当前设备浏览器里。

云同步端点

输出包里有 cloudflare-sync-worker.js，这是一个轻量 Cloudflare Worker 同步后端示例。部署 Worker 后绑定一个 KV 命名空间，变量名使用 TRAINLOG_KV。部署完成后，把 Worker 地址填到 TrainLog 的“同步端点”。

同步密钥可以自己设置，例如一串随机字符。请不要用生日、手机号这种容易猜到的内容。

备份和迁移

如果暂时不部署云同步，也可以在“复盘”页面使用“导出备份”和“导入备份”。这不是自动同步，但可以先让你把手机数据迁移到电脑，或把电脑数据迁移到手机。

开发预览方式

Start-TrainLog.bat 只是开发预览工具：它会让同一 Wi-Fi 的手机临时访问电脑上的 TrainLog。这个模式需要窗口保持开启，不适合正式长期使用。

正式使用请部署到 HTTPS，这样就不需要电脑服务窗口。
